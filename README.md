# Inventario Faena

App de control de inventario de obra (entradas, salidas, stock por obra, seguimiento contra Bodega Central) hecha en un solo archivo HTML — sin instalación, sin servidor.

## Cómo usarla

Abre `Inventario_Obra.html` en Chrome o Edge (necesita uno de estos dos por la función de sincronización con carpeta y lectura del Excel de Bodega Central).

Usuarios de prueba: `admin/admin`, `supervisor/supervisor`, `bodega/bodega`. Cámbialos por unos propios apenas entres, desde Configuración.

## Importante: este repositorio no contiene datos reales

El archivo `Backup_Faena_Latest.json` (con los materiales, entradas y salidas reales de la obra) **no se sube aquí** — vive solo en la carpeta sincronizada del computador. Este repositorio es únicamente el código de la app.
